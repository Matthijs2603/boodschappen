# Boodschappen

Een mobiele pagina met de aanbiedingen van Albert Heijn, Vomar en Lidl in Heiloo.

Deze repo bevat alleen de pagina en het weekbestand (`week.json`). Beide worden elke maandag en donderdag automatisch bijgewerkt door een GitHub Action in een andere repo. Wijzig hier dus niets met de hand, want dat wordt overschreven.
